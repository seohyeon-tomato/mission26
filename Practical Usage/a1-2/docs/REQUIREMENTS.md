# A1-2 필수 조건 대조표

기준: 사용자가 제공한 「Python 응용: API 활용 국내 여행지 추천 프로그램 개발」 미션 원문.

## 원문의 표현 차이 처리

- 본문은 `-date`, 예시는 `--date`이므로 둘 다 지원합니다.
- 본문에서 1일 일정이 필수이므로, 마지막 예시의 “선택” 표시와 관계없이 필수로 구현합니다.
- 파일명은 본문의 “실행 날짜 기준”을 따르고 여행 날짜는 결과 안에 기록합니다.
- 날씨·행사는 실시간 검증 데이터가 아니라 계절 경향·행사 후보로 안내합니다.

## 제출 준비 상태

구현과 모의 테스트 자료는 준비했습니다. **실제 Gemini/Kakao 키를 사용한 통합 실행과 실제 생성 결과 검토는 남아 있습니다.** 모의 결과를 실서비스 호출 증거로 간주하지 않습니다. 따라서 미션 최종 통과를 보장하거나 실호출 검증 완료라고 표시하지 않습니다.

선택 과제인 복수 지역, 캐싱 및 웹 UI는 범위에서 제외했습니다.
