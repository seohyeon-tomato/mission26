# SLIG 서비스 기획서

## 목적과 타겟 사용자
좋아하는 소지품 조합을 사진과 함께 기록하는 개인 스크랩북. 자신의 아이템을 정리하고 비슷한 제품을 검색하고 싶은 사용자가 대상이다. MVP 데이터는 해당 브라우저에만 저장되며 다른 방문자와 공유되지 않는다.

## 페이지 구성
| 화면 | 핵심 기능 |
|---|---|
| Feed | 저장한 기록 카드 탐색, Detail 진입 |
| Upload | 사진·기록 정보·아이템 입력, AI 후보 확인, 저장 |
| Detail | 큰 사진·아이템 목록, 네이버 쇼핑 제품 검색 |
| About | 서비스 목적, 기록 → 확인 → 탐색 3단계 안내 |

SLIG 로고는 Feed, 상단 FEED / UPLOAD / ABOUT는 해당 화면으로 이동한다. 로그인·회원가입은 비기능 UI다. 디자인은 DESIGN.md 및 v4 원본을 기준으로 한다.

## AI 기능
- 입력: 상품명과 옵션(각 120자 이내). 사진은 AI에 보내지 않는다.
- 처리: 입력 중단 900ms 후 `/api/product_match`에 POST → Python 함수가 Codyssey OpenAI 호환 API 호출 → 제품명·옵션·검색어 JSON 검사.
- 출력: “이 제품 맞아요?” 후보. 사용자가 확인해야 아이템을 저장할 수 있다.
- 가치: 자유롭게 적은 제품 정보를 쇼핑에 사용할 검색어로 정리한다.
- 제한: 실시간 상품 데이터베이스 조회가 아니다. 실재 제품·재고·가격·정확한 제품 일치를 보장하지 않는다.
- 변경: 상품명이나 옵션이 달라지면 기존 확인을 해제하고 새 후보를 받는다. 동일 입력은 한 입력 세션에서 캐시한다.
- 실패: 빈 입력은 호출하지 않는다. 입력 길이 초과, API 실패, 시간 초과, 비정상 JSON을 안내한다. 자동 재시도하지 않고 사용자 재시도만 허용한다.
- Detail: 저장된 searchQuery로 쇼핑 검색 링크만 만든다. AI 재호출은 없다.

## 저장 및 운영
localStorage에 사진·기록·사용자가 확인한 아이템을 저장한다. 브라우저 데이터 삭제 시 기록이 사라질 수 있다. 손상된 데이터를 자동으로 삭제하지 않으며 저장 공간 부족 시 성공 처리하지 않는다. API 키는 Python 서버 환경변수에서만 읽는다.

## 제출 기준
1. 배포된 Vercel URL: 메뉴 이동, 반응형, 실제 AI 입력 → 결과 확인.
2. GitHub 저장소: 프론트와 api/ 구분, 커밋 이력.
3. README: 소개, 스택, 실행·배포, 배포 URL, 환경변수 설정.
4. 이 기획서: 목적·사용자·페이지·AI 입력/출력/실패 기준.
5. 증빙: 데스크톱·모바일·실제 AI 동작 화면, AI 코딩 도구 대화/화면.

현재 단계: v4 화면 연결, 독립 로직·실제 Codyssey AI 브라우저 검증 완료. GitHub 원격 업로드와 Vercel 공개 배포는 미완료.
